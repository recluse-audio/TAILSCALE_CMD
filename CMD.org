* set pi host
#+NAME: Set-Pi-Host
#+KIND: reference
Edit ~pi_host.conf~ at this repo's root, one line: ~PI_HOST=user@tailnet-hostname~.
Find the tailnet hostname with ~tailscale status~ once the pi has run
~RD_CMD/CONFIG/COMMON/TAILSCALE/setup.sh~ and been authorized in the browser.

* connect to tailnet
#+NAME: Connect
#+KIND: manual
#+PLAIN: Joins this computer to the tailnet and lets peers SSH in, key-free.
#+DESC: runs tailscale up --ssh, then lists every device on the tailnet
#+OUTPUT: no files, connects the network interface and prints a login URL on first run
#+NEXT: run List-Cameras once the pi shows up in the peer list
#+BEGIN_SRC sh
sudo tailscale up --ssh
tailscale status
#+END_SRC

* list cameras
#+NAME: List-Cameras
#+KIND: ui_script
#+PLAIN: Shows which of the pi's four USB webcams are present, as /dev/videoN.
#+DESC: SSHes into the pi over the tailnet and lists /dev/video* plus v4l2-ctl detail
